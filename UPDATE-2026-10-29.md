# Product Companion and the autonomous coordinator

This update adds **Product Companion** to the main navigation. It can inventory
a published WooCommerce catalog, compare confirmed supplier mappings and retain
field-level findings and evidence. The monthly coordinator keeps a current
window of up to 99 products and prepares the next 99, with four browser workers
by default. Supplier limits and authentication still determine actual capacity.

## What changed

- Durable audit cycles, supplier-fair queue refill, monthly evidence namespaces,
  elapsed time and restart recovery. Uncertain operations stay held instead of
  being sent again.
- An optional Muse director using an existing OpenRouter profile. Compact
  reviews have token/request limits, durable spending reservations and a $25
  monthly cap. Readiness requires a dedicated provider key with a compatible
  monthly spending limit. Collection does not need model calls.
- Separate production-read and protected staging-write connections, environment
  inventories, baseline receipts, supported repair previews, revision checks,
  backups, storefront rechecks and rollback. Production releases require human
  approval and a separate release connection.
- Saved connector and preview credentials can be reused without pasting them
  again. Credential fields clear after a verification attempt; the verified
  connection state determines whether a connection is ready.
- A lightweight authenticated published-catalog endpoint avoids rendering
  customer prices during inventory. The staging connector keeps upstream
  preview authentication separate from WordPress application-password handling.
- Expanded 4over quantity evidence, conditional-coverage checks and replay
  protections. Missing or historical evidence remains unknown. Test quote
  fixtures use synthetic amounts; private supplier evidence stays local.

## Update and find the setup

Choose **Update Hermes → Check for updates → Install tested release** from a
clean `main` checkout started by `scripts/start-local.sh`. Review paused and held
work before resuming. Reload the dashboard when prompted.
Finish saving any entered provider or preview credentials before reloading;
unsaved form fields do not survive a page reload.

Open **Product Companion → Environment baseline and release readiness → Staging
preview protection** for the normal staging preview username/password. Keep the
connector token separate. Provider profiles remain under **Sources & AI**;
choose the director profile under **Schedule and AI settings**.

## Activation requirements

Scheduling and AI reviews remain disabled by default. Before activating the
office service, complete environment backups/alignment, verify the protected
connections and spending limit, register trusted checkout/rate fixtures and run
the Standard Print pilot. Install the supervised service on the actual office
Mac mini; updating another Mac does not install it there.

Current automatic typed writes support verified custom-CSV costs, priced row
additions and document links. Unsupported calculator families, unresolved source
domains, routing changes and new shipping algorithms stay in the review/Codex
queue. Unknown checks cannot make a product green. Shipping models need current,
independent comparable holdouts; a historical sample is insufficient.

See the [full setup and operating guide](docs/AUTONOMOUS-COMPANION.md) for the
service installer, baseline verification, recovery and adapter boundaries.
