# Automatic supplier collection update

Hermes can run supported campaign collection through its own software worker,
without an AI provider supervising each selection. Start it from **Campaigns →
Automatic supplier collection** after signing in through the supplier browser
opened by Hermes. See the [usage and update guide](docs/AUTOMATIC-COLLECTION.md).

The worker saves plans, task ownership, exact source receipts and continuation
cursors. Finite batches rotate between eligible products; suppliers share their
existing request limits. Interrupted selections with uncertain results remain
held instead of being silently submitted again. The 99-product setting controls
queue capacity, not simultaneous supplier tabs.

Printograph repairs cover native process and proof controls, dependent option
ordering, quantity and turnaround observations, and current-page price evidence.
The automatic worker has saved continuing live progress for Staggered Cut Flyers,
Acrylic Boards and Cardboards. These are partial collections, not finalized
products.

The 4over package profile includes native quantity expansion, source dependency
readiness, blank default trim handling, project-label handling and strict summary
checks. Its latest live trials still hold selections on turnaround readiness or
unproved rendered totals. Those integrations need further work. Offline tests
do not establish live quote success, product availability or complete coverage.

Validation on the installed source: **691 tests and 38 subtests passed** across
25 regression modules; the TypeScript/Vite dashboard build passed. Browser tests
use local fixtures. Published source excerpts preserve their byte hashes;
price-response fixtures are explicitly synthetic and are not supplier quotes.

This software update does not publish WooCommerce products. Hermes records
supplier costs; storefront markup and shipping stay separate. Open size/set-count
domains and unsupported supplier controls require compatible source contracts
before automatic collection can cover them.

When updating an existing installation, pause collection and stop the service,
pull this update, run `(cd frontend && npm ci && npm run build)`, then restart with
the existing data directory. Keep your saved data and supplier browser profiles.
Review held tasks before resuming; do not reset their evidence to force a retry.
